# Food Delivery Example

This fictional example demonstrates a domain-first knowledge chain for one storefront feature:

> Food categories should appear before restaurants.

Start at [knowledge/index.yaml](knowledge/index.yaml), then enter the [storefront domain](knowledge/storefront/README.md).

The storefront chain:

1. [Product context](knowledge/storefront/product-vision.md)
2. [RFC](knowledge/storefront/rfcs/FD-RFC-001-categories-before-restaurants.md)
3. [Decision Record](knowledge/storefront/decisions/FD-DR-001-categories-before-restaurants.md)
4. [Information Architecture](knowledge/storefront/ia/FD-IA-001-storefront-discovery.md)
5. [User Flow](knowledge/storefront/flows/FD-FLOW-001-category-first-storefront.md)
6. [Specification](knowledge/storefront/specs/FD-SPEC-001-category-first-storefront.md)

No application code belongs in this example. The purpose is to show how product knowledge flows into implementation-ready behavior.
