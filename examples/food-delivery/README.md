# Food Delivery Example

This fictional example demonstrates a complete knowledge chain for one feature:

> Food categories should appear before restaurants on the storefront.

The chain:

1. [Product context](product-vision.md)
2. [RFC](rfcs/FD-RFC-001-categories-before-restaurants.md)
3. [Decision Record](decisions/FD-DR-001-categories-before-restaurants.md)
4. [Information Architecture](design/FD-IA-001-storefront-discovery.md)
5. [User Flow](design/FD-FLOW-001-category-first-storefront.md)
6. [Specification](specs/FD-SPEC-001-category-first-storefront.md)

No application code belongs in this example. The purpose is to show how knowledge flows from product intent to implementation-ready behavior.
