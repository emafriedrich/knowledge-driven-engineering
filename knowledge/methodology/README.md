# Methodology Domain

This domain contains canonical knowledge for Knowledge-Driven Engineering itself.

Start here when changing the methodology, templates, validator, or agent instructions.

## Retrieval Path

1. Read `knowledge/index.yaml` to confirm the domain.
2. Read this file for the domain map.
3. Read the current spec or flow that matches the change.
4. Read active decisions from `decisions/index.yaml`.
5. Read historical decisions only when supersession or rationale matters.

## Contents

- `product-vision.md` defines the product goal for this repository.
- `rfcs/` stores methodology change proposals under discussion.
- `decisions/` stores methodology Decision Records and their current projection.
- `specs/` defines artifact and metadata behavior.
- `flows/` defines knowledge evolution.
- `prompts/` stores scoped agent context.
