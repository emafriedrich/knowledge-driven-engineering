# DR-001: Use ADR as the decision artifact name

## Context

Architecture Decision Record is a familiar term in software engineering. The first naming proposal used `ADR` because many engineers recognize it.

## Decision

Use `ADR` as the decision artifact name.

## Consequences

The name created a mismatch with the methodology. This repository records product, UX, design, security, infrastructure, and business-rule decisions in addition to architecture decisions.

## Status Note

The team later replaced this decision with [DR-004](DR-004-use-decision-record-name.md). Keep this record as historical context.
